# v0.1.0 — experimental Switch 2 firmware

Direct Bluetooth support for the **8BitDo Ultimate 2 Wireless**, based on its
1.09 firmware. This is an on-controller firmware modification, not a PC driver.
Do not flash it to other controller models.

This release adds real LE 2M radio support, 512-byte ATT transport with expanded
buffers, Nintendo pairing/input handling, and a corrected horizontal D-pad
mapping. The searching LED remains active until the Nintendo session is ready.

## Install on Windows

Extract the release ZIP. Install Python 3 and the HID dependency:

```powershell
py -m pip install hidapi
```

Connect the controller by USB, then run from the extracted folder:

```powershell
py u2wflash.py list
py u2wflash.py flash 8bitdo-u2w-switch2-v0.1.0.bin --yes
```

The flasher checks image integrity, writes changed application sectors, verifies
the result, and resets the controller. Keep USB connected until it finishes.
Use only with the exact Ultimate 2 Wireless model. Retain your original firmware
and device backup for recovery; personal backups are not included in this release.

Unplug USB, select Bluetooth mode, and power on while holding **Y**. On Switch 2,
open **Controllers → Change Grip/Order**, then press **L+R**.

If recovery mode is needed, hold **L1+R1 while connecting USB**. The recovery USB
device is `2dc8:3208`; the normal flasher uses `2dc8:310b`. Recovery mode requires
the appropriate recovery tooling; the normal flash command is not a recovery
command.

## Validation and limits

Switch 2 registration and physical inputs have been demonstrated on one unit.
The corrected horizontal D-pad mapping was verified on the Switch after
installation. Host tests cover the mapping, pairing crypto, protocol, and runtime.

The transport implementation passed live PC tests at 2M and MTU 512, including
a full-size incoming ATT write, 150-byte replies, input streaming, and intact
buffer guards. Full-size 512-byte outgoing responses were not exercised.

Reconnect across power cycles, persistent bond recovery, console wake, rumble,
motion, and extended gameplay are not fully validated. Motion reports currently
contain fixed data. This is an experimental prerelease, not official 8BitDo firmware.
